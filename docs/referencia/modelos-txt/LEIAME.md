# Configurações em `.txt` dos modelos Avicena e AnKing

Coloque nesta pasta (`docs/referencia/modelos-txt/`) o(s) arquivo(s) `.txt` com as configurações de:
- **Frente** (Front Template)
- **Verso** (Back Template)
- **Estilo** (Styling / CSS)

para os modelos:
1. **Avicena** (usado tanto como modelo **Básico** quanto **Cloze**)
2. **AnKing** (usado para **Cloze único** e **Clozes múltiplos** / *One by one*)

> **Nota:** Já existem versões exportadas anteriormente em `docs/referencia/modelos/avicena/` e `docs/referencia/modelos/anking/`. Assim que você colocar o(s) `.txt` aqui, podemos atualizar ou sincronizar os arquivos de referência com a sua versão mais recente.
